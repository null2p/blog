# Welcome to My Blog!

안녕하세요! 제 블로그에 오신 것을 환영합니다. 이 블로그는 **Next.js**, **MDX**, 그리고 **Liquid Glass**를 사용하여 만들어졌습니다.

## 주요 기능

이 블로그는 다음과 같은 특징을 가지고 있습니다:

- **정적 사이트 생성**: GitHub Pages에서 무료로 호스팅 가능
- **MDX 지원**: 마크다운에서 React 컴포넌트 사용 가능
- **Liquid Glass UI**: 아름다운 유리 효과 디자인
- **빠른 성능**: Next.js의 최적화된 빌드 시스템
- **태그 시스템**: 주제별로 글을 쉽게 찾을 수 있습니다

## 기술 스택

```typescript
const techStack = {
  framework: 'Next.js 16',
  styling: 'Tailwind CSS',
  content: 'MDX',
  ui: 'Liquid Glass React',
  deployment: 'GitHub Pages',
};
```
