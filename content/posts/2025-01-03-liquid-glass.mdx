# Liquid Glass UI로 멋진 디자인 만들기

Liquid Glass는 Apple의 디자인에서 영감을 받은 유리 효과를 React 컴포넌트로 쉽게 구현할 수 있게 해주는 라이브러리입니다.

## Liquid Glass란?

Liquid Glass는 다음과 같은 특징을 가진 UI 효과입니다:

- **투명도**: 배경이 비치는 유리 같은 효과
- **블러**: 부드러운 배경 블러 처리
- **굴절**: 빛의 굴절 효과
- **반응성**: 마우스 인터랙션에 반응

## 설치

```bash
npm install @nkzw/liquid-glass
```

## 기본 사용법

가장 간단한 사용 예시:

<LiquidGlassPanel className="p-8 mb-8">
  <div className="text-center">
    <h2 className="text-2xl font-bold mb-2">Beautiful Card</h2>
    <p>This is a live component!</p>
  </div>
</LiquidGlassPanel>

```tsx
<LiquidGlassPanel>
  <div className="card-content">
    <h2>Beautiful Card</h2>
    <p>With Liquid Glass effect</p>
  </div>
</LiquidGlassPanel>
```

## 커스터마이징

다양한 props로 효과를 조정할 수 있습니다:

<div className="grid grid-cols-1 md:grid-cols-2 gap-4 mb-8">
  <LiquidGlassCard displacementScale={20} blurAmount={0.02}>
    <div className="p-4 text-center">
      <p>Low Effect</p>
    </div>
  </LiquidGlassCard>
  <LiquidGlassCard displacementScale={100} blurAmount={0.1}>
    <div className="p-4 text-center">
      <p>High Effect</p>
    </div>
  </LiquidGlassCard>
</div>

```tsx
<LiquidGlassCard
  displacementScale={70}    // 변위 효과 강도
  blurAmount={0.0625}       // 흐림 정도
  elasticity={0.15}         // 탄성
>
  {/* 콘텐츠 */}
</LiquidGlassCard>
```

### 주요 Props

| Prop | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `displacementScale` | number | 70 | 변위 효과 강도 |
| `blurAmount` | number | 0.0625 | 흐림 정도 |
| `elasticity` | number | 0.15 | 액체 느낌 강도 |

## 실전 예제

블로그 카드 컴포넌트:

<div className="mb-8">
    <LiquidGlassCard displacementScale={60} blurAmount={0.05}>
        <div className="p-6">
          <h3 className="text-xl font-bold mb-2">My Awesome Post</h3>
          <p className="opacity-80">This is how a blog card looks with Liquid Glass effect.</p>
          <div className="mt-4">
             <LiquidGlassButton>Read More</LiquidGlassButton>
          </div>
        </div>
    </LiquidGlassCard>
</div>

```tsx
function BlogCard({ post }) {
  return (
    <LiquidGlassCard
        displacementScale={60}
        blurAmount={0.05}
    >
        <div className="p-6">
            <h3>{post.title}</h3>
            <p>{post.description}</p>
        </div>
    </LiquidGlassCard>
  );
}
```

## Tailwind CSS와 함께 사용

Liquid Glass는 Tailwind CSS와 완벽하게 호환됩니다:

<LiquidGlassPanel className="p-6 shadow-xl border-t border-white/20">
    <span className="text-center font-bold text-transparent bg-clip-text bg-gradient-to-r from-pink-500 to-violet-500 block">
        Styled with Tailwind CSS
    </span>
</LiquidGlassPanel>

```tsx
<LiquidGlassPanel className="p-6 shadow-xl border-t border-white/20">
    {/* 콘텐츠 */}
</LiquidGlassPanel>
```

## 성능 고려사항

Liquid Glass 효과는 GPU를 사용하지만, 성능을 위해 다음을 고려하세요:

1. **효과 강도 조절**: 필요한 만큼만 사용
2. **모바일 최적화**: 낮은 성능 기기에서는 효과 줄이기
3. **레이어 수 제한**: 너무 많은 효과 중첩 피하기
